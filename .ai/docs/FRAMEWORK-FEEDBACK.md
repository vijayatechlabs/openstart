# OpenStart framework feedback

Local log of framework gaps, bugs, and improvements discovered in this project.
Each entry should be filed as an issue on the framework repo:
**github.com/vijayatechlabs/openstart/issues**

Run `bash .ai/framework/feedback.sh "<message>"` (or `/feedback` in Claude Code)
to add an entry and get the ready-to-file GitHub issue text.

See `.ai/framework/FEEDBACK.md` for the full pipeline.
